## 全量代码安全与性能审查（WenMa + WenMaService）

### 项目技术栈基线
- 前端 `WenMa`：Vue 3.5 + Vite 8 + Element Plus 2.14 + axios，23 个源文件
- 后端 `WenMaService`：Spring Boot 3.5.16 + MyBatis-Plus 3.5.16 + Druid 1.2.20 + java-jwt 3.19.2 + aliyun-sdk-oss 3.18.4
- Git remote: https://gitee.com/lv-junyu-sumingyue/question-code-education.git

### 关键结论（供后续修复追踪）
1. **P0 JWT 认证失效**：`JwtTokenInterceptor:23` 用 `url.contains("/stucourses/ids/${id}")` 字面量比对（含 `${id}` 占位符），永不命中 → 全站放行；且用 `jwt.parseToken()`（JWT.decode 不验签）而非 `verifyToken()`。注册路径是 `/**`。
2. **P0 支付可绕过**：前端点"已支付"直接调 `POST /stucourses/add`，后端无支付/金额/幂等校验，`stuId` 取自请求体可伪造。
3. **P0 明文密码**：`StuServiceImp:30` / `EmpServiceImp:26` 用 `.eq(getPassword, password)` 做查询条件；无任何登录限流/验证码。
4. **P0 密码渲染**：`Login.vue:62` `{{ LoginInfo }}` 把含密码的对象插值进页面。
5. **P0 密钥入库**：`application.yml` 已 git 跟踪且仓库**无 .gitignore**，49 个 target/ 产物入库，153 个跟踪文件。
6. **P1**：上传无服务端校验 + `getBytes()` 全量入堆（前端 `space.vue:30` size 判断逻辑写反，2MB 限制失效）；`getAllCourses` 全表无分页；`/courses/list` N+1；`@vueuse/core` 幽灵依赖（未声明，靠 EP 传递依赖 hoist）。
7. **肯定项**：数据层全用 LambdaQueryWrapper 预编译，无 SQL 注入；前端无 v-html/innerHTML；OSS 凭证走环境变量。
