## 修复：登录页首次加载报 JSON.parse SyntaxError

**现象**：启动前端进登录页即抛 `SyntaxError: JSON.parse: unexpected character at line 1 column 1`，堆栈指向 `request.js:22`。

**根因**：`WenMa/src/Utils/request.js` 请求拦截器把「未登录」写成中文哨兵值再解析：

```js
const user = localStorage.getItem('userInfo') ? localStorage.getItem('userInfo') : '未登录'
config.headers.token = JSON.parse(user).token   // 未登录时 parse('未登录') → 第 1 列首字符非法
```

首次访问 localStorage 无 `userInfo` → `user = '未登录'` → JSON.parse 必崩；登录过一次后有值反而不报错，所以只在首次访问登录页触发。

**修复**：改为无值则不设 token 头，解析失败时清理脏数据：

```js
const user = localStorage.getItem('userInfo')
if (user) {
  try { config.headers.token = JSON.parse(user)?.token ?? null }
  catch { localStorage.removeItem('userInfo') }
}
```

**验证**：prettier --check 通过，acorn --ecma2020 --module 解析通过。

## 后续：统一 userInfo 读写，收口全部裸 JSON.parse

新增 `WenMa/src/Utils/userInfo.js`，导出 `getUserInfo / setUserInfo / clearUserInfo / getToken`：
- `getUserInfo()`：无值返回 null；解析失败自动 `clearUserInfo()`；非对象结果判为非法
- `setUserInfo(data)`：`data` 为空直接跳过，杜绝 `JSON.stringify(undefined)` 写入 `"undefined"`
